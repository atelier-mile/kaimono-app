## 管理方針

1. アプリの機能、品物データ、署名鍵、識別情報を変更しない。
2. 署名鍵・認証情報・PC固有設定・詳細なローカル資料・ビルド生成物はGitに含めない。
3. アプリ再構築に必要なソース、Android設定、依存関係の固定ファイル、画像素材を保存する。
4. 署名鍵はGitHubと別に保管・復元する。ソースだけでは既存アプリ更新用の署名鍵を再現できない。
5. 今回はGitHubへの接続・送信を行わない。
6. 初回コミットの成否と識別番号はGit履歴、およびPC内のGit管理開始報告書で確認する。
